## Configuration de la base de données
Pour utiliser votre base de donnée voici les étapes à suivre :
1. Copier `db.properties.example` en `db.properties` et renseigner `db.url` / `db.user`.
2. Définir la variable d'environnement `DB_PASSWORD` avec le mot de passe de la base, evous aurez alors accès à votre base de donné
